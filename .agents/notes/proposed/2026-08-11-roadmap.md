# Agent Note: 后续路线图（自 llm_ctx/ROADMAP 迁移）

Status: proposed

## Problem

原 `docs/llm_ctx/ROADMAP.md` 记录的功能规划在文档重构中被移除，若不保存将丢失设计意图（含封面来源演进路径等已论证的方向）。

## Alternatives considered

- 直接删除：git 历史可回溯，但失去「当前评审中的方向」语义。
- 迁移为 proposed note：保留规划，与新文档框架一致（决策与规划进 `.agents/notes/`）。

## Proposal

### 近期（1-2 个迭代）

- 规则验证：在加载规则时验证正则表达式的有效性
- 交互式规则生成：添加向导式规则生成功能
- 并行处理：对于大文件，考虑并行处理章节

### 中期（3-6 个迭代）

- 封面自定义模板接线：`--cover-template <FILE>`，让 `template export` 导出的 `cover.svg` 真正作为生成源（当前为参考副本）
- 封面参数可配置：尺寸、书名单行字符数/行数、字体族、配色（`--cover-size` 或 rules `[cover]` 段）
- 生图服务接入：支持 comfyui 等生图服务作为封面来源（如 `--cover comfyui:<配置>`）
  - 演进路径：将封面来源收敛为 `CoverSource` 枚举（`None | File | Auto | Remote`），`generate_cover` 保持「产出 PNG」抽象不变，仅新增 `Remote` 变体与调用分支

### 长期（半年及以后）

- GUI 版本：便于非技术用户使用
- 云服务集成：支持从云存储读取和写入文件
- 插件系统：支持插件扩展功能
- 规则市场：提供共享规则的平台
- 自动规则生成：基于机器学习自动生成规则

## Acceptance criteria

- 任一规划项立项时，以本 Note 为起点补充问题与验收清单，移入 proposed 独立 Note。

## Risks

- 中期封面相关三项相互耦合，需先定 `CoverSource` 枚举再展开。
- 生图服务接入依赖网络，与「离线可预测」核心承诺冲突，需明确边界。
