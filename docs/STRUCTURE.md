# 文档目录结构

```
docs/
├── MAP.md                 # 文档索引（唯一入口）
├── STRUCTURE.md           # 目录结构维护（本文件）
├── system-map.md          # 模块总览与依赖关系
├── data-flow.md           # 数据流与流程
├── cli.md                 # CLI 参数参考
├── config.md              # 配置项参考
├── templates.md           # 模板与样式参考
├── delivery.md            # 构建与发布
└── llm_ctx/               # 状态同步与决策
    ├── STATUS.md          # 当前状态快照
    ├── ROADMAP.md         # 里程碑规划
    ├── CHANGELOG.md       # 变更日志
    └── decisions/         # ADR/技术决策记录
```
