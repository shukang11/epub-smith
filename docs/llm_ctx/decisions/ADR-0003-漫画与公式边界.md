# ADR-0003 不支持漫画与公式（输入模型边界）

- 日期：2026-08-11
- 状态：采纳
- 背景：讨论未来扩展场景（漫画、数学公式）时，评估当前 CSS 结构是否需为其预留。
- 决策：
  - **不为此调整结构**：EpubSmith 输入是 TXT 纯文本，漫画（图片）与公式（LaTeX/MathML）在输入侧就无法表达，属于输入模型问题而非 CSS 结构问题。
  - 不为不存在的输入添加"漫画容器""公式"等死代码 class（避免重蹈 `.container` 死代码覆辙）。
  - 若未来扩展，需换输入格式（如 Markdown/HTML）并新增渲染器，是独立特性，单独规划。
- 影响：
  - 范围聚焦纯文字书（TXT→EPUB），CSS 结构保持最小（标题/段落/目录/封面）。
  - 页面结构规范化（`.container` 内容容器）是通用能力，对未来扩展不冲突（容器内可加元素）。
