# 里程碑规划

按“近期 / 中期 / 长期”维护，避免一次性堆叠过多任务。

## 近期（1-2 个迭代）

- ✅ 进度显示：添加进度条，特别是处理大文件时（已完成）
- 规则验证：在加载规则时验证正则表达式的有效性
- 交互式规则生成：添加向导式规则生成功能
- 并行处理：对于大文件，考虑并行处理章节

## 中期（季度内）

- 更多输出格式：考虑支持其他电子书格式（如MOBI）
- 更多输入格式：支持更多文本格式，如Markdown、HTML

## 长期（半年及以后）

- GUI版本：考虑开发GUI版本，便于非技术用户使用
- 云服务集成：支持从云存储读取和写入文件
- 插件系统：支持插件扩展功能
- 规则市场：提供共享规则的平台
- 自动规则生成：基于机器学习自动生成规则
