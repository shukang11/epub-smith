# 变更日志

本文件记录对外可感知的改动，遵循语义化版本。

## [Unreleased]

- 命令行子命令优化：重构为清晰的子命令结构
  - `convert`：TXT转EPUB的主要命令
  - `preview-outline`：打印章节大纲
  - `preview-dry-run`：预览详细章节结构
  - `snapshot-save`：保存章节结构快照
  - `snapshot-load`：从快照生成EPUB
  - `template-export`：导出样式模板
- 新增 `doctor` 诊断命令
  - 输出章节数据异常（重复章节号、倒序章节号）统计与样本
  - 输出规则风险提示（“张”单位误判风险、中文数字范围不足风险）
  - 输出建议执行的 `preview` / `convert` 命令，降低上手门槛
- 默认样式升级为方案 C（可读性优化）
  - 保留首行两字符缩进
  - 调整为中等段落间距
  - 默认保留段内换行（`white-space: pre-line`）
- 默认章节规则强修正（误判分层治理）
  - 默认禁用“张”章节单位与 `！1、` 句式触发规则，降低正文误判
  - 默认支持 `零/〇/百/千/万/两` 等中文数字，减少大章节号漏识别
  - 默认章节单位调整为 `章/节/卷/回`，源文本错号仍保持仅检测告警
- 规则验证：在加载规则时验证正则表达式的有效性
- 交互式规则生成：添加向导式规则生成功能

## [0.2.0] - 2026-01-07

### 新增功能

- 支持多文件输入，可同时处理多个TXT文件
- 支持从标准输入（stdin）读取内容，使用 `-` 作为输入参数

### 技术改进

- 优化了文件处理逻辑，提高了多文件处理效率
- 改进了命令行参数处理，支持更灵活的输入方式

## [0.1.0] - 2026-01-07

### 新增功能

- 实现了TXT到EPUB的核心转换功能
- 命令行界面支持多种参数和选项
- 自定义规则文件支持
- 多种输入文件编码检测和指定
- 章节大纲显示和dry-run模式
- 进度条显示功能
- 多语言支持（i18n）
- 性能计时和分析
- 章节连贯性检查

### 修复和改进

- 优化了大文件处理性能
- 改进了错误处理和提示信息
- 增强了代码可维护性和可读性

### 技术栈

- Rust语言开发
- 使用clap库构建CLI
- 使用tera模板引擎
- 使用indicatif库实现进度条
- 支持多语言国际化
